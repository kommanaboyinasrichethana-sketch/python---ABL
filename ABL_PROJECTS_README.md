## Folder structure
Each project folder contains:
- `main.py` — complete Python source code
- `README.md` — problem statement, objectives, assumptions, algorithm, Mermaid flowchart, pseudocode, test cases, screenshot instructions, and conclusion

## How to run
1. Open a project folder.
2. Run `python main.py` (or `python3 main.py`) in a terminal.
3. Enter the sample values listed in that project's README.
4. Capture your own terminal screenshot for submission.

## Syllabus coverage
Variables, data types, operators, conditional statements, loops, strings, pattern generation, lists, nested lists, tuples, and tuple unpacking.

**Note:** Railway fare and traffic penalty values are hypothetical classroom assumptions, not official charges.
